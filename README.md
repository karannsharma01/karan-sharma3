# Karan Sharma — portfolio

Plain HTML/CSS/JS, no build step.

```
karan-sharma/
├── index.html      page content
├── css/style.css   design tokens + styles
├── js/main.js      tabs + footer year
├── assets/         images (add yours here)
└── deploy.ps1      creates the repo, pushes, enables GitHub Pages
```

Preview: open `index.html`, or run `python -m http.server`.
Deploy: `.\deploy.ps1` (or push manually and enable Pages: Settings → Pages → main / root).
Live URL: https://karannsharma01.github.io/karan-sharma/
